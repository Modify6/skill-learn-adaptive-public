① 为什么多播 IP 没有对应任何物理机器？

D 类地址的虚拟性：224.0.0.0 ~ 239.255.255.255 是逻辑频道号，不是某块具体网卡的门牌号。
映射法则：多播 IP 会通过算法折叠映射到一个特定的组播 MAC 地址（以 01:00:5e 开头）。网卡芯片只认这个特殊 MAC 过滤器！

② 为什么智能交换机能做到“静默过滤”？

痛点：笨交换机遇到不认识的多播包，会退化成广播全网乱发。
解法：现代交换机内置 IGMP Snooping（组播侦听）。当小车向网线发送 IGMP 加入报告时，交换机在硬件芯片里记住小车接在几号口，后续只往该口送数据，其他人零打扰！

③ 为什么 Domain ID 能成为终极防串台防火墙？

端口硬隔离：DDS 多播发现端口 = 7400 + 250*DomainID。
物理现象：Domain 0 在听 7400，Domain 1 在听 7650。同一个房间两台小车即使多播组相同，操作系统的 UDP 栈一看端口没开，在网卡驱动层当场无情丢弃！
