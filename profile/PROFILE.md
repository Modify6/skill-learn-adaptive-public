## 触发器（按已验证强度排序）

1. **跨域结构类比**（最强）：把新知识映射到已熟悉系统的物理结构上。
   - 示例：局域网多播寻人 = 项目微信群聊里 @ 人，认出后私聊交换名片。
   - 准则：类比源必须来自真实生活经验，不能生搬硬套。
2. **机器内部模型**："这东西底下是一台什么机器"。
   - 示例：TCP = 操作系统内核划拨的两个带锁环形水池；UDP = 贴 8 字节小标签直接踢飞的无状态发信机。
3. **框图+高保真交互课程网页**（深学/回炉系统化首选交付物）：
   - 三列工作台：真实系统调用代码 / 物理机器与内部队列 / 实时报文与硬件监控账本。
   - 配套「↺ 重玩本关」精准回退重放与「⟲ 清除全部进度」双击确认防误触，内置 `localStorage` 自动断点续走。
4. **constraint-first**：先讲"为什么必须这样设计，不这样物理世界上会坏掉什么"。
5. **具体例子 + 极端事故案例**：抽象定义配一个最小实例和一个把参数推到极端的情形（如 TCP 队头阻塞导致遥控小车停顿后暴冲撞墙、纯 UDP 丢失急停命令导致无人机撞树）。

## 反模式（会让我糊，避免）

- 符号/公式/步骤的堆砌，没有结构和"为什么"（高中式填鸭错配）
- 一遍求全懂（应多遍渐懂：第一遍只拿形状，自底向上打地基）
- 学完即求全景清晰：期待"一想到 X，所有知识点清晰展现"（大脑不是硬盘回放，终态是骨架常驻+细节按需加载）
- 抄原文式笔记（应写结构：框图、名字、职责）
- 只加重复次数不换表征（只加重复只供原料，换表征才按开关）
- 闭卷标准：以为必须凭记忆默写出全部代码（合法开卷：骨架记住、细节现查）

## 节奏与自我认知

- 学习曲线 = 长平台期 + 突然相变（开光）。平台期不是没学，是结构在深层记忆底下搭。
- 重复供原料，表征按开关，两者不可互相替代。
- **前置依赖阶梯是复合型知识的导航仪**：面对复合型工业中间件或网络协议栈，学习磕绊、穿不起来链路的根因，往往不是当前技术难，而是底层前置砖块不稳。必须先画出「前置依赖阶梯树」，按图索骥逐层打牢。
- 教学交付物要课程化：显式起点（空场）→ 分关任务卡（起点/任务/观察点/收编）→ 毕业小测 → 终点（自由模式）。
